RDR2-Vulkan-DLSSFG 1.0
kunSurenioRBG

Download the full installation ZIP from the GitHub release, close the game,
and extract its contents beside RDR2.exe. Back up existing mod files first.
Retain your existing INI if you want to keep your preferences.

The package contains the official ASI loader, main ASI, default configuration,
and the matching Core, Streamline, XeSS and diagnostic runtime files.
Required legal notices are consolidated in licenses/NOTICES.txt.
The game and system prerequisites are described in README.md.
