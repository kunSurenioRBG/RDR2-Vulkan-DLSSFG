# 1.0

RDR2 Vulkan Frame Generation by **kunSurenioRBG**.

- Native control panel with live metrics and Generation, Display and Diagnostics tabs.
- Clickable YouTube and GitHub links in the footer.
- CUDA-backed NVIDIA identity selection and XeSS 2x pacing fixes.
- Complete installation bundle with the official ASI loader, default INI, corrected core, matching Streamline/XeSS runtimes and diagnostic helper.
- Clean ZIP root: only installation files. Mandatory legal notices are consolidated in `licenses/NOTICES.txt`; documentation stays on GitHub.

## Installation

Download **RDR2-Vulkan-DLSSFG-v1.0-full.zip** and extract it beside `RDR2.exe` with the game closed. Back up existing mod files and retain your own INI if you want to keep your preferences. Start the game with Vulkan and in-game DLSS enabled. Press Insert or your configured menu key.

The frame-generation fixes were tested on an RTX 3080 Ti and improved smoothness was confirmed. The footer and menu were rendered in isolation at two scales. Runtime hashes, archive contents, Windows x64 architecture and static imports were checked; a clean-machine gameplay test was not performed. The game, graphics driver and system runtime prerequisites are listed in the repository documentation.

XeSS 3x/4x and unofficial GPU unlocks remain experimental. Original and third-party license notices are preserved.
